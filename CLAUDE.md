## UI & Design Constraints (Anti-Slop)
- **Typography:** NEVER default to `Inter`, `Roboto`, or system fonts unless explicitly requested. Always pair a distinct display font with a clean, intentional body font.
- **Colors:** BANNED from using generic purple-to-blue gradients, default Tailwind indigo/violet accents, or overly saturated neon dark-mode tropes. Use a restrained, high-contrast palette (1 primary, 1 muted accent, neutral surfaces).
- **Layout & Hierarchy:** 
  - Do NOT wrap every group of elements in bordered cards with drop shadows. Use whitespace, padding, and typography scale to create hierarchy.
  - Avoid redundant subheadings that state the obvious (e.g., do not put "Manage your settings" directly under a "Settings" header).
- **Icons & Decor:** Never use emojis as UI icons or bullet points. Use consistent, minimal vector icons (e.g., Lucide, Phosphor) sparingly.
- **Mock Data:** Never invent fake testimonials, placeholder user avatars, or generic "Acme Corp" stats unless asked.
## Writing & Copy Constraints
- **Break the Rule of Three:** Never default to lists or examples of three. Use one, two, or four+ items based on actual content needs.
- **Sentence Variety:** Never write three consecutive sentences of similar length. Mix short, punchy statements with longer, connected thoughts.
- **Banned AI Vocabulary:** Never use overused LLM filler words like *delve, tapestry, testament, landscape, elevate, seamless, game-changer,* or *unlock*.
- **Tone:** Skip corporate pep talks and hedging. State the point plainly without introductory fluff or wrap-up summaries.
